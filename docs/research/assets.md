# Asset research record

Date: 2026-09-14. Constraint: the development environment's egress policy allows GitHub,
GitLab, PyPI, npm and Ubuntu archives, and blocks Sketchfab, Poly Haven, Kenney, Quaternius,
Poly Pizza, ambientCG, OpenGameArt, Freesound, Hugging Face (Objaverse mirror), Wikimedia and
most other asset hosts. Only sources whose per-item licence could be read and whose files could
be fetched and hashed were eligible.

## Vehicles

| Candidate | Licence | Verdict |
| --- | --- | --- |
| Škoda models on Sketchfab (Octavia, Fabia by various authors) | per model, unverifiable; downloads account-gated; host blocked | rejected |
| KhronosGroup/glTF-Sample-Assets `CarConcept` | CC-BY-4.0 (Eric Chadwick / DGG) + Khronos logo marks | rejected: futuristic concept car, no realistic passenger-car interior |
| KhronosGroup/glTF-Sample-Assets `ToyCar` | CC0-1.0 | rejected: toy |
| Godot demo projects `3d/truck_town` vehicles | CC-BY-4.0 (Godot demo assets) | rejected: cartoon low-poly trucks |
| Procedural car generated by project code | MIT (project) | **adopted** for the first vehicle ("Lipan 1.2", fictional compact hatchback) |

Decision recorded in `plan.md` section 14. The vehicle system stays data-driven and the glTF
import path (`docs/asset-pipeline.md`) is kept so a legally usable Škoda model can be added later
as a data task.

## Textures, buildings, vegetation, signs, sounds

Procedural generation by project code (MIT). Reasons: hosts with CC0 scans are unreachable;
procedural content is deterministic, tunable and licence-clean; Czech sign faces are geometric
and reproducible from the decree's shapes; engine and vehicle sounds are synthesised from the
simulation state, which is also what the dynamic audio requirement asks for.

This was the September 14 baseline. OpenGameArt and Freesound previews became reachable on
September 25; [Phase 14 source and listener review](../audio-previews/phase14-recorded-source-review.md)
records the candidates. None has been integrated into the game.

## Reference data (facts, not assets)

- Czech plates: `docs/research/czech-plates.md`.
- Czech roads, markings, signs: `docs/research/czech-roads.md`.
- Vehicle parameters: public technical data of B-segment cars (e.g. Škoda Fabia III 1.0 TSI
  70 kW: 160 Nm at 1800--3500 rpm, 5-speed manual, length 4108 mm, wheelbase 2564 mm, kerb
  weight ~1010--1100 kg, per manufacturer technical data sheets found via web search) inform the
  fictional first vehicle's definition without copying any proprietary model.
