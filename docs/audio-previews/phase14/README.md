# Phase 14 device-free listening pack

These 14 clips are lossless FLAC encodings of 44.1 kHz, 16-bit stereo PCM from the simulator's
actual `VehicleAudio` mixer. `carsim-audiopreview` drives fixed vehicle and weather snapshots
through the mixer without opening an audio device, display or simulator window. Each clip starts
with a new mixer and is deterministic. All sound is generated by project code; no recordings
were imported. Except for the actual startup sequence, each excerpt discards 0.51 s of
steady-state mixer warm-up so the opening is not an artificial engine fade-in. The WAV output
was rendered twice and matched byte-for-byte. Every FLAC here
decodes to that exact PCM; hashes are in [SHA256SUMS](SHA256SUMS).

| Clip | Listening cue |
| --- | --- |
| [startup](startup.flac) | Off until 0.35 s, starter until 1.25 s, then catch and idle. Check the two joins. |
| [idle](idle.flac) | Steady 850 rpm. Check tone, hiss and any periodic mechanical feel. |
| [RPM sweep](rpm_sweep.flac) | 850 → 5850 → 850 rpm over seven seconds. Check harmonic transitions and aliasing. |
| [load](load.flac) | Fixed 3000 rpm, light/full/light load at 2 and 4 s. Check that load adds body without a click. |
| [lift-off](lift_off.flac) | Loaded 4500 rpm until 1.5 s, then closed throttle and falling rpm. Check the overrun. |
| [shifts](shifts.flac) | Manual gear changes at 1.5, 3 and 4.5 s. Check dip, clunk and recovery. |
| [engine braking](engine_braking.flac) | Closed throttle, 3500 → 1700 rpm. Check burble density and continuity. |
| [tyre/road](tyre_road.flac) | 70 km/h: asphalt, gravel at 2 s, cobbles at 4 s. Engine off to expose contact texture. |
| [wind](wind.flac) | Airborne 0 → 130 km/h over five seconds. Engine off to expose airflow. |
| [rain](rain.flac) | 50 km/h rain, spray and wipers; switch to cabin at 3 s. Check roof drops and wiper level. |
| [snow](snow.flac) | 50 km/h packed snow; switch to cabin at 2.5 s. Check contact texture and attenuation. |
| [traffic pass-by](traffic_passby.flac) | One car moves left to right across the listener, closest at 3 s. Check panning and level. |
| [cabin/exterior](cabin_switch.flac) | 70 km/h cruise, cabin at 2 s, exterior at 4 s. Check both transitions. |
| [helicopter](helicopter.flac) | 5, 6, 7, 8 Hz rotor modes, changing every 1.5 s. Check thrum and turbine balance. |

To regenerate WAV files, build the existing OPENGLES3 preset and run:

```sh
cmake --build --preset opengles3 --target carsim-audiopreview
build/opengles3/bin/carsim-audiopreview build/audio-preview/phase14-review
```

The tracked FLAC files were encoded losslessly with `ffmpeg -c:a flac`. The preview tool applies
the mixer's default 0.8 master gain before writing PCM, matching stream playback gain. Each
file was checked for a valid stereo WAV source, exact duration, lossless FLAC round trip and
clipping; the highest preview sample peak was 0.580 of full scale. Those checks establish
technical integrity only. **No speaker or headphone listening judgment is recorded yet**;
the subjective pass and mix tuning required by P14-040/P14-041 remain open. These snapshots
also isolate sound states rather than replaying a full physics drive.
